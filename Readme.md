# Introduction

What started as a simple dream eventually became years of dedication.

I always wanted to create something that could stand beside the greatest Final Fantasy XII mods ever made. That ambition led me to learn English, study game modding, understand the game's internal systems, and ultimately choose the PlayStation 2 version as my platform.

While most projects focus on the PC release, I wanted to push the original hardware beyond what seemed possible.

The result is **Revenant Job System**—a complete gameplay overhaul that redesigns nearly every major gameplay system while preserving the identity that made Final Fantasy XII unforgettable.

Every feature has been handcrafted, tested, balanced, and refined to deliver what I believe is the definitive way to experience **Final Fantasy XII International Zodiac Job System**.

# Installation

1. Download the latest release from the **Releases** section.
2. Extract the archive.
3. Place an English-patched **Final Fantasy XII International Zodiac Job System** ISO beside the `bin_izjs` folder.
4. Rename the ISO to:

```
ff12zj.iso
```

5. Run `patch.exe`.
6. Wait for the patching process to finish.
7. Enjoy the new Revenant Job System experience.
